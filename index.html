4. AI image generation connection

This starter app organizes your script, reference images and storyboard. Actual AI artwork generation still needs a secure image-generation service. For now, you can attach generated images to each panel; they will appear in the storyboard and printed comic. Never put a private API key in this HTML file.

The provider can have usage charges. We will keep the interface provider-neutral and show costs before batch generation where the provider supports estimates.

PanelForge is an independent open-source starter project. No API keys are requested or stored by this page.
