4. AI image generation

A secure server endpoint is required; the API key must stay on that server. The repository now includes a Cloudflare Pages function for OpenAI image generation. Enter its URL and access code after deploying it. Generation may cost money; PanelForge asks for confirmation before sending image requests.

Generation runs one panel at a time and sends your chosen reference images to the configured image provider. Check the provider's current pricing before generating an entire issue.
